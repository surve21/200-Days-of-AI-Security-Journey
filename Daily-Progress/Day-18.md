##  Cybersecurity Project

### File Integrity Monitor (FIM)

**Status:** ✅ Completed and Published

The File Integrity Monitor is designed to detect unauthorized changes to monitored files by creating and comparing cryptographic hash values.

### Concepts Applied

* File Integrity Monitoring
* Cryptographic Hashing
* SHA-256
* File Change Detection
* Baseline Creation
* Python File Handling
* Cybersecurity Automation

### Project Work Completed

* Designed the FIM workflow.
* Implemented file hashing.
* Created a baseline for monitored files.
* Implemented file integrity checking.
* Tested the project by modifying monitored files.
* Verified that changes could be detected.
* Completed project documentation.
* Published the project on GitHub.

##  Security Perspective

FIM is an important defensive security technique because unexpected file modifications can indicate unauthorized activity, malware, tampering, or configuration changes.

Understanding FIM also provides a foundation for later learning about **host-based monitoring, SIEM, SOC investigations, and incident detection**.
